# Conformance corpus

Each program in this directory uses only language features and globals: no actors and no imports. Next to each `<name>.ts`, `<name>.stdout` holds what Node printed, and `<name>.status` holds the exit status when it is not 0. `crates/bouy-cli/tests/conformance.rs` runs each program with `bouy run` and asserts that stdout and the exit status equal these files, so the tests never run Node. A program avoids the documented differences of section 3 of `docs/design/beam-runtime.md`. For example, it prints objects with a single key or with keys in sorted order, and it uses integers below 2^53.

To add a program or to change one, run `scripts/freeze-expectations.sh tests/conformance` and commit the new `.stdout` and `.status` files with the program. The script is the only place that runs Node. Then run `cargo test -p bouy-cli --test conformance`. A program without a `.stdout` file fails the test. On a failure, the test prints the exit statuses and the lines that differ for each program: `-` for Node and `+` for Bouy.
